## 確定値と暫定値

| 区分 | 数値 | 理由 |
|---|---|---|
| **確定**（条件を添えればそのまま使える） | 誤訳の検出 20/20（A は 0/20）、誤警告 0/20・0/60、曖昧な意図の未確認送信 0/8（A は 8/8）、不要な確認 0/17、理解の食い違い 10/10・警告 0/5 | 最終のコードでの実測。照合は 3 回繰り返しても同じ |
| **暫定**（「評価環境での目安」と書く） | 応答時間（A 1.6/6.7 秒、D 6.4/14.3 秒） | Gemini の呼び出し時間の合計（意図と訳は並列なので長い方＋照合＋訳し直し）で、Firestore・通信・画面の時間は含まない。評価用のプロジェクトの小さい割り当てで、429（混雑）の再試行を含む。本番では未測定。標本 45 件（意図 25＋否定・数量 20）。D は C と同じ 1 回の実行の値（問診メモ・Auditor は相手に届くのを待たせないので含まない） |
| **暫定**（実行ごとにゆれる・件数が少ない） | 医学的な曖昧さの確認候補 12/14、説明不足の指摘 4/10（実行により 4〜5/10）、teach-back 3/3 | 1 回の実行。件数が少ない |
| **使わない方がよい** | 「文脈で決まる発言を正しく訳した」A 12/17・D 16/17 | 語の一致による近似の採点。取りこぼし 1 件は意味が正しかった |
